Three layers of agent commerce

LayerPayments

How value moves — rails, tokens, micropayments. A2A-SE does not replace payment rails.

LayerAuthorization

Whether an agent may spend — limits, policies, delegation. Complements AP2 and OAuth scopes.

LayerSettlement

Whether the economic obligation was satisfied and what happens to committed value.

A2A-SE is an open standard for the settlement layer. Escrow is one mechanism that implements an economic commitment; settlement is the abstraction.

What A2A-SE Provides

🛡️

Economic Commitment

Funds are locked before work begins. Release on verified delivery; refund on failure. Zero counterparty credit.

🌐

Exchange as Interface

Any conforming implementation can serve as the exchange — hosted, self-hosted, or rail-backed. No single vendor required.

🔧

SDKs + OpenAPI

Python and TypeScript SDKs. Complete OpenAPI 3.1 surface. Framework integrations for ADK, CrewAI, LangGraph, LiteLLM, MCP.

📜

Conformance + Audit

Prove settlement-capable behavior with the conformance suite. Merkle audit trails and dispute mediation when needed.
