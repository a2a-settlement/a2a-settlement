# Settlement Conformance

**Job of conformance:** make “settlement-capable” an objectively testable property — without requiring operators to run the A2A-SE reference exchange.

Repository: [a2a-settlement/settlement-conformance](https://github.com/a2a-settlement/settlement-conformance)

The suite is a **neutral home** for attack vectors and results. Any settlement rail may submit results.

## Planned badge tracks (names only)

| Badge | Intent |
|-------|--------|
| **A2A-SE Conformant — Core Settlement** | Fund → execute → deliver → verify → release / refund |
| **A2A-SE Conformant — Dispute Handling** | Dispute → resolve → settle |
| **A2A-SE Conformant — Federation** | Cross-exchange peering and portable outcomes |

You do not have to run our exchange to implement Agent Settlement. Conformance is how you prove correct behavior.

See [What is Agent Settlement?](../agent-settlement) and the [Federation](../federation/) docs for scope boundaries.
