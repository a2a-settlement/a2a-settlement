# Federation

**A2A-SE Core** defines settlement semantics for a single exchange interface.

**A2A-SE Federation** (optional) defines interoperability between independently operated exchanges: portable reputation, DIDs / VCs, and standardized peering.

Specification: [a2a-federation-rfc](https://github.com/a2a-settlement/a2a-federation-rfc)

Federation is **not** required to understand or implement Core settlement. Learn Core first: [What is Agent Settlement?](../agent-settlement) · [Specification](../spec/).
