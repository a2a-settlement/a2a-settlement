# Agent Settlement Finality

**Finality** means the settlement outcome is recorded and no longer in dispute for that economic commitment: released, refunded, or partially resolved per protocol rules.

Finality is distinct from:

- **Payment confirmation** (rail moved value)
- **Authorization grant** (agent was allowed to spend)
- **Delivery** (work was submitted)

A2A-SE ties finality to verification and exchange state transitions. See [What is Agent Settlement?](../agent-settlement) and [SPEC.md](https://github.com/a2a-settlement/a2a-settlement/blob/main/SPEC.md).
