# x402 vs A2A-SE

**x402 moves or gates value at the edge. A2A-SE finalizes whether a task obligation was satisfied.**

| | x402 | A2A-SE |
|---|------|--------|
| Primary question | Can I access / pay for this call? | Was multi-step work settled correctly? |
| Layer | Payments / access | Settlement |
| Multi-turn task escrow | — | Yes |
| Release / refund / disputes | — | Yes |

An agent may use both: x402 at the gate, A2A-SE for the task. See [protocol comparison](../architecture/protocol-comparison).
